# Звезды крупным планом

Самостоятельный сайт и RSS для нового канала Дзена. Содержит шесть страниц; первые четыре статьи, опубликованные вручную, исключены из ленты. Две оставшиеся статьи передаются с категорией `native-draft`.

## Размещение

Сервис Render: Static Site. Репозиторий: `mkdigitaly-pixel/mkdigitaly-pixel.github.io`. Ветка нового канала: `stars-rss`. Корневая папка нового сайта: `stars-site`. Команда сборки: `node build.mjs`. Папка публикации: `dist`. Платный сервер и база данных не требуются. При сборке адрес берётся из `RENDER_EXTERNAL_URL`, поэтому страницы, изображения, RSS и карта сайта используют домен, назначенный этому сайту. Сервис собирает только свою папку; данные другого канала не используются. Основная ветка другого канала не изменяется.

При другом хостинге задайте `SITE_ORIGIN` с фактическим HTTPS-адресом сайта. До назначения адреса публикацию не выполнять. Сборка без адреса останавливается.

Код подтверждения хранится в `config.json` и выводится в `head` главной страницы. При смене адреса проверьте, не выдал ли Дзен новый код.

## Материалы

Данные: `articles.json`. Изображения и оформление: `public`. Связей с данными и RSS другого канала нет. `sourceOrigin` применяется только для замены прежнего адреса изображений при переносе; в готовые страницы этот адрес не попадает.

Перед публикацией выполните `node --test` с тем же адресом в переменных окружения. Проверяются код подтверждения, исключение четырёх статей, постоянство GUID, собственные адреса и наличие всех изображений.

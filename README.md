# Знаете ли вы что — статьи и RSS

Сайт: https://mkdigitaly-pixel.github.io/
RSS: https://mkdigitaly-pixel.github.io/rss.xml
Репозиторий: mkdigitaly-pixel/mkdigitaly-pixel.github.io, main.

## Ежедневный выпуск

С 23 октября 2026 года планируются три выхода в день: 12:00, 15:00 и 18:00 по Екатеринбургу (UTC+5). Уже назначенная статья занимает свой слот и входит в дневной лимит. Между выходами одного дня — не менее трёх часов. Скрипт lib/schedule.mjs выбирает свободные слоты и учитывает минимум один час для отложенной публикации.

Подготовка следующей тройки выполняется отдельным ежедневным заданием в приложении. Полностью готовые тексты и обложки добавляются в data/articles.json и public/covers. Для подготовки нужны доступные рабочие инструменты; статистический анализ опирается только на свежие подтверждённые данные владельца. Закрытая статистика и рабочие материалы не публикуются в репозитории.

## Даты сайта и Дзена

sitePublishedAt — дата открытия полного текста на сайте.
publishedAt — отдельная дата Дзена, которая передаётся в pubDate RSS.
Будущая дата Дзена не скрывает уже открытый материал на сайте.

Первые десять материалов были подготовлены для первичной проверки ленты. 22 октября владелец сообщил об одобрении RSS и появлении статей в канале. Добавлены ещё три материала и отредактирована статья о днях рождения. Адреса, GUID и ранее назначенные даты сохраняются.

Лента использует format-article, полный content:encoded с документированными элементами HTML, PNG-обложки шириной 1672 пикселя и реальные размеры enclosure. Код подтверждения сайта хранится в config.json. Доступ роботу разрешён в robots.txt.

## Проверка и публикация

Для сборки нужен Node.js 24. Внешних зависимостей нет:

    npm test
    npm run build

GitHub Pages публикует dist через GitHub Actions при сохранении в main и по прежнему расписанию обновлений. .qa содержит только локальные проверки.

Обновление RSS и дата pubDate задают план. Фактическое время импорта и появление материала в канале зависят от Дзена. Не создавайте новый GUID для правки старой статьи.

# Знаете ли вы что — сайт и RSS

Сайт: https://mkdigitaly-pixel.github.io/
RSS: https://mkdigitaly-pixel.github.io/rss.xml
Репозиторий: mkdigitaly-pixel/mkdigitaly-pixel.github.io, ветка main.

## Даты сайта и Дзена

Все десять полных текстов открыты на сайте для первичной проверки RSS.
Для первых двух сохранены даты 12 и 14 октября 2026 года. Остальные восемь открыты на сайте 15 октября; задним числом даты не меняются.

В data/articles.json поле sitePublishedAt отвечает за доступность и дату текста на сайте.
Поле publishedAt сохраняет первоначальную дату для Дзена и выводится в pubDate RSS.
Будущие даты Дзена не скрывают уже доступные на сайте материалы из ленты.
Исходные GUID и адреса первых трёх статей сохранены.

Даты в Дзене: 12, 14, 16, 18, 19, 21, 23, 25, 26 и 28 октября 2026 года, 18:00 по Екатеринбургу (UTC+5).
Лента использует format-article и не использует native-draft.
Это запланированные даты, а не подтверждение публикации в Дзене.
Импорт начнётся после одобрения ленты. Если дата уже прошла к моменту одобрения, точное время фактического выхода зависит от Дзена.

## Первичная проверка RSS

По инструкции https://dzen.ru/help/ru/website/rss-modify.html при первой разметке нужно минимум 10 материалов и минимум 3 публикации на сайте за последний месяц.
Лента содержит 10 полных текстов с отдельными доступными страницами, постоянными GUID, датами, описаниями и PNG-обложками шириной 1672 пикселя.
Внутри content:encoded используются документированные элементы HTML.
Размеры и объём файлов изображений соответствуют enclosure и media:content.
В robots.txt доступ разрешён.

15 октября получен отказ RSS с общим сообщением о несоответствии контента.
После сверки с инструкцией исправлены недостаточное количество материалов и разметка.
Это устраняет найденные несоответствия, но решение о подключении остаётся за Дзеном.
Владение сайтом уже подтверждено; текущий код проверки хранится в config.json.
После обновления сайта RSS необходимо снова отправить на проверку в Студии.

## Обновление сайта

GitHub Pages использует GitHub Actions. Сборка запускается при сохранении в main и по ежедневному расписанию.
Дополнительные ключи, пароли и внешние библиотеки не нужны.
Для сборки нужен Node.js 24:

    npm test
    npm run build

Публикуется только dist. Временные проверки находятся в .qa.
В публичном репозитории доступны тексты и изображения сайта; статистика канала, локальный журнал и скачанный курс в него не входят.

Настройка Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

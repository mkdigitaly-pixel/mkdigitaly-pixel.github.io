# Знаете ли вы что — сайт и RSS

Подготовленный сайт для GitHub Pages: `https://mkdigitaly-pixel.github.io/`.
RSS: `https://mkdigitaly-pixel.github.io/rss.xml`.
До успешного размещения эти адреса не подтверждены.

## Публикация

Репозиторий: `mkdigitaly-pixel/mkdigitaly-pixel.github.io`, ветка `main`.
В Settings → Pages выбрать источник GitHub Actions. В workflow используется только стандартный токен этого репозитория; дополнительные ключи и пароли не нужны.

GitHub Free требует публичный репозиторий для Pages. Поэтому исходники и все три подготовленных текста будут доступны в репозитории сразу. На сайте и в RSS полные тексты появляются только после даты выхода. В репозиторий не включены статистика канала, локальный журнал, скачанный курс, аккаунты и служебные данные старого хостинга.

## Расписание

Даты статей: 12, 14 и 16 октября 2026 года, 18:00 по Екатеринбургу. Сборка включает только статьи, дата которых уже наступила. Автоматические обновления запускаются ежедневно в 18:05, 18:20 и 18:35 по Екатеринбургу. Повторные запуски помогают при задержке первого. GitHub может задержать или пропустить запуск, поэтому точное время появления статьи не гарантируется. Дзен читает RSS по своему расписанию.

В публичном репозитории GitHub отключает расписание после 60 дней без активности. После добавления следующих статей проверить, что workflow включён.

## Следующие статьи и метатег

Тексты и даты находятся в `data/articles.json`, изображения — в `public/covers`. При изменении текста, обложки или времени сборка запускается после сохранения в `main`.

Код проверки Дзена находится в `config.json`. Перенесён ранее предоставленный код. Для нового адреса Дзен может выдать другой код — его нужно заменить перед проверкой владения новым сайтом. Успешная проверка метатега и импорт RSS ещё не выполнены.

## Проверка

Нужен Node.js 24. Внешние библиотеки и установка зависимостей не требуются.

```text
npm test
npm run build
```

`dist` содержит только публикуемые файлы. Тестовые сборки находятся в `.qa` и на сайт не отправляются.
